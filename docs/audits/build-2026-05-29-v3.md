## Fixes applied

1. **`docs/qa/brochure-pdf-checklist.md` §2 (Page count)** — baseline
   revised from 150 to **240 ± 25** with explicit note that row 8
   ("very short non-empty pages") is the decisive regression signal,
   not absolute page count.

2. **`docs/qa/brochure-pdf-checklist.md` §3 (Duplicate prose)** — added
   four formal exclusion classes:
   - bibliographic tokens (author names, venues, DOI/arXiv/viXra IDs)
   - `pdftotext -layout` hyphenation tail lines
   - ASCII flow-diagram bars (`|`, `v`, `^`)
   - cross-chapter echoes involving `kind='unified'` digest chapters

3. **`scripts/qa_duplicate_prose.py`** — new Python script that
   implements all four exclusions in one pass. Output: `CLEAN` or a
   list of real-duplicate blocks. Drops shell quoting issues that
   made the old one-liner unreliable.

4. **Baseline summary table** in checklist updated; row 8 marked as
   "decisive regression signal".
