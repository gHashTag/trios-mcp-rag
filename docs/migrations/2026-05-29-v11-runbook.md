## Rollback procedure

If the rebuild produces a broken PDF or QA fails:

```bash

BEGIN;
TRUNCATE ssot_brochure.chapters;
\COPY ssot_brochure.chapters(slug,kind,order_key,title,body_md,illustration_url) FROM '/tmp/pgbackup/all_chapters_pre_v11_20260529T133416Z.tsv' WITH (FORMAT csv, DELIMITER E'\t', HEADER true);
COMMIT;

# 2. Restore template
cp /tmp/pgbackup/chapter.template.tex.pre_v11_20260529T133416Z templates/chapter.template.tex

# 3. Rebuild
cargo build --release
./target/release/trios-mcp-rag build-pdf --book-mode \
  --out-dir generated/out --build-dir generated/build \

```

## Why each P0 fix is safe

1. **B10 compound renumber** is monotonic per kind and preserves
   `(original order_key ASC, slug ASC)` ordering — visual order of the
   PDF cannot change.
2. **B16 H1→H2 demotion** is targeted by `regexp_replace` with a
   chapter-specific anchor pattern (`P1 Appendix [A-Z]`,
   `P3 Appendix [A-Z]`, `Appendix F[.\\d]*`); the first H1 (chapter
   title) is left untouched by anchor. Verified by post-migration
   `LENGTH(body_md) - LENGTH(REPLACE(body_md, E'\n# ', '')) / 3 = 0`.
3. **B15 unified-symmetry-article** is a special case: all body `# `
   become `## ` and pipeline auto-injects `# {title}`. The pipeline
   path is `pipeline.rs:278`, exercised by `authority-outreach-templates`
   and `cover-letter-symmetry` already in v10 — well-tested code path.
4. **B11 title vs H1 alignment** uses single-line non-greedy anchored
   regex (`^# [^\\n]+`) with the `n` flag so only the first H1 changes.
5. **B3 hfuzz bump** is purely about warning thresholds; it cannot
   change layout because the overruns are already inside the tolerated
   `\sloppy` regime.
