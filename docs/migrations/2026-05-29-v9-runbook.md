## Migrations (run in order — each is its own transaction in `2026-05-29-v9-fixes.sql`)

1. **V1 — Mojibake `∈fty` / `∈t`.** Two `regexp_replace` passes wrapping the affected token as `$\infty$` / `$\int$` inline math.
2. **V2 — ASCII math snippet wrap.** Five `regexp_replace` passes for greek-name caret-star tokens (`mu^*`, `lambda^*`, `gi^*`, `muT(`), then single-letter math anchors (`[FRTCSPGgM]^[*+]`) with negative lookbehind on `$` and `\` to skip already-wrapped instances.
3. **V3 — `limsupL` fragmented.** Single regex `\mlimsupL\M → $\limsup_{L}$` (plus `liminfL` symmetry).
4. **V4 — Floor/ceil ASCII → Unicode.** Four `regexp_replace` passes for `lfloor`, `rfloor`, `lceil`, `rceil`. Only matches when not preceded by `\` (i.e. not already a TeX macro).
5. **V5 — Raw `phi^N` → inline math.** `(?<!\\)\mphi\^(-?[0-9]+) → $\varphi^{\1}$`.
6. **V6 — Multi-digit greek subscripts.** `psi17 → ψ₁₇`, `theta13 → θ₁₃`.
7. **V7 — `S3AI` body leak.** Single chapter (`p3-13-phd-integration`); ASCII tagline → `S³AI`.
8. **V8 — Claim-status badges.** PL/pgSQL helper `pg_temp.inject_badge(slug, badge)` injects `\statusVerified` / `\statusEmpirical` / `\statusOpen` / `\statusHighRisk` after the H1 line of each chapter, no-op if already badged. 31 new chapters badged this pass.
9. **V9 — Sum/prod tokens.** Eight `regexp_replace` passes covering `sumc`, `sumk`, `sumi`, `sumn`, `sumj`, `prodk`, both with and without `=N` subscript marker.
10. **V10 — Joined floor/ceil cleanup.** `lceillog → ⌈log` for the one residual joined-token instance.
11. **Cross-cutting — `\(...\)` → `$...$` conversion.** Because pandoc default markdown didn't recognise our `\(...\)` deliminted math, all 23 instances converted to `$...$` form.
12. **Cross-cutting — verbatim-block dedent.** Three theorem blocks in `p3-04-pellis-expansion` and `p3-05-projection` were indented at 8 spaces (triggering pandoc `\begin{verbatim}`); dedented to 2 spaces so inline math renders.

