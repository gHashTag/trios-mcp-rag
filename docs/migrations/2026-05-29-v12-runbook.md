## Rebuild PDF

```bash
export PATH="$HOME/.cargo/bin:$HOME/.local/bin:/usr/lib/postgresql/17/bin:$PATH"
cd /home/user/workspace/trios-mcp-rag-repo

rm -rf generated/out generated/build
mkdir -p generated/out generated/build

./target/release/trios-mcp-rag build-pdf --book-mode \
  --out-dir generated/out --build-dir generated/build \
  --pdf-name GOLDEN_CHAIN_2026-05-29.pdf
```

Reference baseline for this build: **259 pages, ~3.4 MB,
SHA-256 `6d2e29ed32cc92b4aea32a0c639f7f16c646d94e1aa4adba97787869ec79293d`**.
Bytes will drift on every rebuild because tectonic stamps
`CreationDate` in the PDF metadata — page count and visible content
are the stable invariants.

## QA Gates

All four must pass before the build is considered done.

1. **No `\tbd` literal leak in PDF text.**

   ```bash
   pdftotext -layout generated/out/GOLDEN_CHAIN_2026-05-29.pdf - \
     | grep -c '\\tbd'
   ```

   Expected: `0`.

2. **No `\status` literal leak in PDF text.**

   ```bash
   pdftotext -layout generated/out/GOLDEN_CHAIN_2026-05-29.pdf - \
     | grep -c '\\status'
   ```

   Expected: `0`.

3. **No smart quote inside `16'h47C0`.**

   ```bash
   pdftotext -layout generated/out/GOLDEN_CHAIN_2026-05-29.pdf - \
     | grep -F $'16\u2019h47C0' | wc -l
   ```

   Expected: `0`.

4. **Visual QA.** Render pages 46, 118, 151, 221, 226 with
   `pdftoppm -r 110 -png … -f N -l N` and confirm:
   - p46 — `fm-13-depin-positioning` shows "TBD: real measurement
     pending" as plain in-line text, not a red box.
   - p118 — `gf-numeric-formats-history` body renders cleanly.
   - p151 — `p2-03-math-preliminaries` ends with a new `## References`
     block (or appears on the following page if pagination shifts).
   - p221 — `gf-format-audit` opens with the **Open conjecture** badge;
     just above, `gf-numeric-formats-history` ends with its new
     References block.
   - p226 — `unified-symmetry-article` opens with the **Empirical fit**
     badge under the auto-injected H1.

## Rollback

If any QA gate fails or the build is rejected downstream:

1. **Restore SSOT.**

   ```bash
   psql "$DATABASE_URL" -v ON_ERROR_STOP=1 <<'SQL'
   BEGIN;
   DELETE FROM ssot_brochure.chapters;
   \copy ssot_brochure.chapters(slug,kind,order_key,title,body_md,illustration_url) FROM '/tmp/pgbackup/all_chapters_pre_v12_20260529T135422Z.tsv' WITH (FORMAT csv, DELIMITER E'\t', HEADER true);
   COMMIT;
   SQL
   ```

2. **Restore template (if it was modified — this run did not touch
   it, so the cp is informational only).**

   ```bash
   cp /tmp/pgbackup/chapter.template.tex.pre_v12_20260529T135422Z \
      templates/chapter.template.tex
   ```

3. **Restore the v11 PDF for hot replacement.**

   ```bash
   cp /tmp/pgbackup/GOLDEN_CHAIN_v11_20260529T135422Z.pdf \
      generated/out/GOLDEN_CHAIN_2026-05-29.pdf
   ```

4. **Document the rollback** by appending a dated rollback note to
   the v12 audit (`docs/audits/build-2026-05-29-v12.md`) before
   re-pushing.

## Trinity-s3ai Cross-Repo Refresh

After the trios-mcp-rag commit lands on `docs/agent-wake-up`, refresh
the published preview in `gHashTag/trinity-s3ai`:

```bash
cd /tmp/trinity-s3ai
./scripts/refresh_compendium.sh \
  /home/user/workspace/trios-mcp-rag-repo/generated/out/GOLDEN_CHAIN_2026-05-29.pdf \
  v12 \
  <trios-mcp-rag-v12-commit-sha> \
  --patch-readme
```

The script:

1. Copies the PDF into `releases/GOLDEN_CHAIN_compendium_v12.pdf`.
2. Re-renders the cover at 110 DPI into `figures/`.
3. Computes the SHA-256 and writes it into `WAVE22_STATUS.md`.
4. Patches six README fields with the new version, commit, sha,
   page count, file size, and date.

Commit + push the trinity-s3ai change with the message template
`docs: refresh GOLDEN CHAIN compendium to v12 (<sha>)`.
