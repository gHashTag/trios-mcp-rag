### 2. P0 — rule 07 §1 (RAGAS CI gate) self-contradiction

**Evidence.** [`docs/agent-rules/07-literature-grounded-refinements.md`](../agent-rules/07-literature-grounded-refinements.md)
§1 declares the RAGAS CI gate **normative** with hard thresholds
(`faithfulness ≥ 0.80`, `context_recall ≥ 0.75`) and states that failing
the thresholds blocks the build. But:

- `ls .github/workflows/` is empty — no CI exists at all.
- `docs/literature/05-cross-cutting.md` (v13 status tags) marks the same
  RAGAS gate as **deferred** with explicit justification ("no
  `.github/workflows/` RAGAS job exists yet; checklist is manual").

A rule cannot be simultaneously normative AND deferred. As written,
rule 07 §1 should fail every current build — but no build is failing
because the gate has no implementation.

**Severity rationale.** Internal inconsistency in the rule set. Future
agents reading rule 07 in isolation will either assume the gate is wired
(it isn't) or silently ignore the section, eroding rule discipline.

**Proposed fix.** Edit rule 07 to add an explicit `**Status: planned —
will become hard once CI is wired**` line on §1, with a forward-ref to
the cross-cutting deferred entry. Same treatment for §3 (alt_text non-null)
and §4 (tectonic version pin) where the predicate also depends on absent
infrastructure.

**Rollback.** `git revert <commit-sha>`.

### 3. P0 — rule 07 §2 references absent schema column

**Evidence.** Rule 07 §2 mandates a non-null `falsification_path` column
in `ssot_brochure.chapters` for every Open-conjecture claim. Actual schema:

```
\d ssot_brochure.chapters
 slug             | text    | not null
 kind             | text    | not null
 order_key        | integer | not null
 title            | text    | not null
 body_md          | text    | not null
 illustration_url | text    |
```

Six columns. No `falsification_path`, no `claim_status`. The rule
references a column that does not exist.

**Severity rationale.** Same as anomaly 2 — internally inconsistent rule.
Falsification paths today live in chapter body Markdown as a labelled
paragraph; the schema-level enforcement is a future migration.

**Proposed fix.** Edit rule 07 §2 to clarify: falsification paths today
live in `body_md` as a labelled "**Falsification path:** …" paragraph;
schema-level enforcement (a `falsification_path` column with a
not-null-when-Open-conjecture check) is **planned** and tracked in
the cross-cutting deferred list. The Markdown-paragraph form remains
mandatory in the meantime.

**Rollback.** `git revert <commit-sha>`.

### 5. P1 — widow/club penalty drift between canon and template

**Evidence.** `docs/literature/05-cross-cutting.md` "No-image-train via
penalty" entry recommends `\widowpenalty=9999, \clubpenalty=9999`.
Actual `templates/chapter.template.tex` lines 4–5:

```
\widowpenalty=10000
\clubpenalty=10000
```

The template is *stricter* than the canon (10000 = infinity, never break;
9999 = nearly infinite, breakable as last resort). The drift is harmless
in behaviour but the canon is wrong about what the code does.

**Severity rationale.** Literature canon is authoritative for **why**;
the template is authoritative for **what is built**. Future agents
reading the canon may "fix" the template down to 9999, weakening the
no-image-train enforcement.

**Proposed fix.** Update the cross-cutting entry text to `=10000` and
keep the explanatory note ("=10000 is `\@M`, LaTeX's infinity sentinel;
9999 would allow a last-resort break which TRIOS forbids"). No code
change.

**Rollback.** `git revert <commit-sha>`.

### 6. P1 — reproducibility hash check absent from QA checklist preamble

**Evidence.** `pdfinfo` on the current baseline PDF prints **no
`CreationDate` line** — tectonic's `SOURCE_DATE_EPOCH` is wired and the
non-determinism source called out in Track 4 has been neutralised. This
is a passed gate, but `docs/qa/brochure-pdf-checklist.md` does not have
an explicit "verify `pdfinfo` does NOT print CreationDate" assertion;
the gate is implicit.

**Severity rationale.** Implicit gates regress silently. A pandoc /
tectonic upgrade could re-introduce CreationDate; without an explicit
checklist line, no agent will notice until reproducible-build sha256
diverges.

**Proposed fix.** Add a row to the operational checklist requiring
`pdfinfo "$PDF" | grep -qv CreationDate` to pass (i.e. CreationDate must
be **absent**). Document the rationale in one line.

**Rollback.** `git revert <commit-sha>`.
