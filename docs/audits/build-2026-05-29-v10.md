## Confirmed v10 anomalies (4 P0 + 1 P1 — all fixed)

1. **V1 (A36, P0)** `p3-13-phd-integration` — v9 regression: orphan `$$`
   created by an aggressive ASCII-math wrap during V2 of v9 produced the
   broken token `$\sum_{k=0}$$\infty$ ck φ-k`. The intermediate `$$` closes
   one inline-math and immediately opens a display block that pandoc would
   try to render as a paragraph-level equation, but the `\infty$` token
   re-opens inline math, so pandoc emits malformed LaTeX. Fixed by
   collapsing the whole expression into a single inline-math span:
   `$x = \sum_{k=0}^{\infty} c_k\,\varphi^{-k}$`. Verified visually on
   page 202 (P3 Appendix A, Definition A.1).

2. **V2 (A37, P0)** `fm-07-olsen-tier-d` — five `Nobel` mentions, the most
   sensitive being the verbatim Prigogine line "I shall certainly present
   you for the next Nobel Prize in Physics." Rule 5 forbids prize / Nobel
   claims **as deliverables**, but allows them **as long-term
   external-validation standards** and as historical material. The
   quotations are between Prigogine / Binnig and Mohamed El Naschie about
   his *separate* E-infinity programme — they are not TRIOS endorsements.
   Fixed by inserting a `\statusHighRisk` badge and an explicit
   disclaimer block before the `### Endorsements` heading: the disclaimer
   states (i) these are biographical context for the Tier-D contribution,
   (ii) they are not peer-reviewed validations, (iii) the future-Nobel
   wording refers to El Naschie's programme and not to this compendium,
   and (iv) TRIOS prize framing remains *external-validation
   standards, never deliverables*, pointing to
   `references/04-claim-status.md`.

3. **V3 (A11/A27, P0)** `london-handout` — odd `$` count (5) because
   `$2M` was unescaped. Fixed with `\$2M`. Post-fix unescaped-`$` count is
   4 (even — `$$ ... $$` display block intact).

4. **V4 (A21, P1)** TOC pollution by `## References` from each chapter
   leaking into TOC as `X.Y References` subentries (14 such lines). Fixed
   globally: `## References` → `## References {.unnumbered}` across all
   42 chapters that use the heading. Pandoc emits `\section*{References}`,
   which is **not** numbered and not added to TOC. Result: 0 References
   subentries in the v10 TOC.

5. **V5/V6 (A6/A7, P1)** ASCII straight quotes and `--` em-dashes. Fixed
   via pipeline change: `pandoc.arg("--from=markdown+smart")` enables the
   pandoc `smart` extension, which converts `"X"` → `"X"`, `--` → `—`,
   `...` → `…` outside code, math, and raw blocks. Verified visually on
   pages 67–68 (Olsen quotations: `"El Naschie was able to..."`,
   `"I'm very impressed..."`, all curly).

## Items explicitly deferred to v11 (or accepted)

- **B17 — heroes absent**: `illustration_url` is NULL for all 69 chapters;
  `ssot_brochure.assets` is empty. PDF has 1 image (cover). This is a
  pre-existing state since at least the v6 backup; pipeline supports
  heroes (`pipeline.rs:265–298`) but no asset blob has been seeded.
  Restoring heroes requires inserting binary PNGs into `assets` and
  populating `illustration_url`. Out of scope for v10 critic-proof pass.
- **B8 — TOC `S3 AI` flatten**: 3 `\addcontentsline` entries render
  `S³AI` as `S3 AI` because `\addcontentsline` flattens Unicode super-
  scripts. Documented v9 limitation; needs `\texorpdfstring`-style
  workaround in the template TOC emitter.
- **B16 — long flat chapters**: 10 chapters have lines >300 chars; pandoc
  reflows correctly but reader-side semantic subheading injection is
  deferred.
- **B18 — PDF/UA-2 tagging**: tectonic does not emit tagged PDFs (`Tagged:
  no`); deferred to post-process via `pdfsigner` or migration to Quarto
  / Typst (see `references/04-reproducible-pdf-pipeline.md`).
- **B19 — `\statusNonClaim` macro** for `p1-acknowledgments` /
  `p2-13-phd-provenance` (and `unified-symmetry-article`, which is a
  multi-section unified article that would benefit from per-section
  badges).
- **B20 — `\nicefrac` migration** for the few ASCII fractions (`1/2`,
  `3/4`) in prose. Cosmetic.
- **B21 — Pellis Definition A.1+ raw ASCII math**: `Q(φ) = Q(5)`,
  `Z≥ 0`, `R>0`, `T = { n · 3k · φp · pi^m · eq : n ∈ Z≥ 1 }` — large
  blocks of unwrapped ASCII math survive from a pre-pandoc-aware era of
  `p3-13`. Pandoc renders them as prose, which is suboptimal but not
  broken. Requires structured rewrite. Deferred.
