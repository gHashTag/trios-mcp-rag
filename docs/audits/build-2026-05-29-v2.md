## Change in this build (vs v1, sha `7084bc7…`, 284 pp)

Root cause of the v1 overshoot was **stock `book.cls` `\chapter`
issuing `\clearpage` internally**, forcing 74 page breaks across the
62-chapter brochure (62 chapter openers + 12 H1 sections promoted to
`\chapter` by `--top-level-division=chapter`).

Fix in `templates/chapter.template.tex`: redefine `\chapter` to lay the
heading **inline** with a soft `\Needspace{0.30\textheight}` guard, no
`\clearpage`, no `\thispagestyle`. TOC bookmarks and section counters
preserved.

Net effect:

| metric                            | v1     | v2     | baseline |
|-----------------------------------|--------|--------|----------|
| pages                             | 284    | 242    | 150      |
| very short non-empty pages (§8)   | 1      | **0**  | 0        |
| short-page signature              | mild   | gone   | —        |

242 vs 150 baseline is now a *content* gap, not a `\clearpage`
regression — §8 short-page count is 0, so the brochure no longer shows
the regression signature described in `docs/qa/brochure-pdf-checklist.md`
§2.
