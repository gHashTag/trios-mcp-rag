# GOLDEN CHAIN build 2026-05-29 — v5 (creative frontmatter)

## Goal

Open the book with something other than a dry TOC. Add **five
unnumbered frontmatter pages** between the cover and the numbered
chapters:

| order_key | slug | section |
|---|---|---|
| 5  | `fm-01a-epigraph`      | Epigraph (Kepler · Wigner · Cameron · anchor identity) |
| 8  | `fm-01b-dedication`    | Dedication |
| 12 | `fm-01c-prologue`      | A Letter from the Authors |
| 15 | `fm-01d-reading-paths` | How to Read This Book (4 reader profiles) |
| 18 | `fm-01e-at-a-glance`   | GOLDEN CHAIN at a Glance (5 numbers · 5 claim-statuses) |

All five start with `# Title {.unnumbered}` so pandoc emits
`\chapter*{...}` + `\addcontentsline{toc}{chapter}{...}` — they appear
in the TOC without a chapter number, in line with academic-book
convention.

## Build

```
./target/release/trios-mcp-rag build-pdf --book-mode \
  --out-dir generated/out --build-dir generated/build \
  --pdf-name GOLDEN_CHAIN_2026-05-29.pdf
```
