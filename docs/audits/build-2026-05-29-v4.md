## Fixes applied

1. **`scripts/clean_tsv_leak.py`** — new Python migration script.
   Dry-run by default. Removes TSV-row contamination from
   `body_md` while preserving any trailing markdown heading.
   Applied to local Postgres (62 chapters); Railway migration
   documented separately (see `docs/migrations/2026-05-29-clean-tsv-leak.md`)
   and requires explicit go-ahead per rule 03.

2. **`src/pipeline.rs` post-merge metadata hook** — after the
   `qpdf --empty --pages` cover merge (which drops the Info dict),
   the build now invokes `exiftool` to re-inject Title, Author,
   Subject, Keywords, Producer, Creator, and Language. Skipped
   silently if `exiftool` is unavailable.

3. **`docs/migrations/2026-05-29-clean-tsv-leak.md`** — full
   migration runbook including backup, dry-run, apply, rollback,
   and verification steps for Railway.
