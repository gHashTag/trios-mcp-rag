## 3. Что Скотт должен подставить

| Поле | Значение |
|---|---|
| Letterhead / address / phone | реквизиты Wisdom Traditions Center, LLC |
| Дата | за **не более 3 месяцев** до подачи на визу |
| Mr. Vasilev passport / DOB / nationality | Дмитрий пришлёт отдельно |
| Business angel name / passport | пользователь подтвердит и пришлёт |
| Issuing post | ближайший UKVI VAC к месту подачи (Moscow, Tbilisi, etc.) |
| Symposium venue / programme reference | если есть подтверждение от Temenos Academy — приложить копию |
| Signature | живая подпись + печать LLC (если есть) |

## 4. Что приложить к визовой заявке (помимо письма)

- Подтверждение участия Скотта в симпозиуме (письмо/email от Temenos Academy)
- Подтверждение бронирования отеля
- Подтверждение обратных билетов
- Банковская выписка за 3 месяца
- Документ о трудовой/деловой занятости в стране проживания
- Эта invitation letter (оригинал)

## 5. Безопасность

- **Не указывать** в письме коммерческую часть (DARPA, инвестиции,
  патенты, продажу чипов) — это переводит визит из категории
  "academic guest" в "business visit" и усложняет процесс.
- **Не предлагать** что Wisdom Traditions Center покрывает расходы —
  это создаёт обязательства sponsor support, которые могут
  усложнить процедуру для обеих сторон.
- **Указать чёткий срок выезда** в конце симпозиума.
