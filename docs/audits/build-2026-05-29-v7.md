## Phase 2 — Fixes Applied

### P0/A1+A2 — Unicode super/sub fallback (Lua)

`filters/force-fullwidth-hero.lua` extended with a `Str(elem)` transformer that
walks every text node UTF-8 byte-by-byte, detects runs of codepoints
`U+00B2`, `U+00B3`, `U+00B9`, `U+207A-U+207F`, `U+2070-U+2079` (superscript)
and `U+2080-U+208E` (subscript), and rewrites each run to a single
`\textsuperscript{...}` or `\textsubscript{...}` `RawInline`. Non-super/sub
text is preserved verbatim. The transformer returns `nil` if no rewrite
fires (zero overhead on chapters that contain no such codepoints).

Verification: generated TeX contains **332** `\textsuperscript` and **59**
`\textsubscript` invocations across the brochure body. Visual check on
page 11 (Strands & Crowns) confirms `S³AI`, `φ²`, `φ⁻²`, `α⁻¹` render
with proper baselines. The cover-page raster still shows `S3AI` (flat) —
that is generated by an upstream GPT-2 art pipeline and is documented in
fm-01g; the body is correct.

### P1/A5+A6+A16 — SSOT migrations

Single transaction in `docs/migrations/2026-05-29-v7-fixes.sql`. Applied:

1. Strip trailing `.` from DOI numbers (`10.NNNN/...` followed by `.` and
   whitespace or punctuation).
2. Prefix bare arXiv IDs (`arXiv 2509.22445` → `arXiv:2509.22445`).
3. Unify `Tier D` → `Tier-D` (two regex variants for before-lowercase and
   before-punctuation).

8 chapters touched; 4 with byte-level delta. Audit queries inside the
transaction confirmed all three target patterns reduced to 0 occurrences.

### P1/A14 — Errata and version history

New chapter `fm-01g-errata-and-versions` (`order_key=20`, `kind=frontmatter`).
Explains the build-date vs. evidence-date convention, the versioning scheme,
the substantive-vs-non-substantive change rule, and lists v1–v7 with
one-line headlines. Two-column Release/Date/Headline table inside.

### P1/A15 — Licence and attribution

New paragraph inserted into `fm-01f-statements`, just before "Use of
generative AI". Splits source code (Apache-2.0) from prose and SSOT
(CC BY 4.0); marks the TRIOS / S³AI wordmarks and the GOLDEN CHAIN
cover engraving as trademarks not covered by the CC BY licence.
